# Documentation Overview

This directory contains detailed documentation for the Group 43 Hex Agent.

## Files

*   **[optimizations.md](optimizations.md)**: A deep dive into the software engineering techniques used to optimize the agent (Memory Pool, Transposition Table, Zobrist Hashing, Bitboards) and the experimental results proving their effectiveness.
*   **[PROTOCOL.md](PROTOCOL.md)**: The specification for the communication protocol between the agent and the game engine.
*   **[walkthrough.md](walkthrough.md)**: A high-level walkthrough of the project structure and key components.
